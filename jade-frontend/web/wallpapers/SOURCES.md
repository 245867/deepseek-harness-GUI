# 壁纸来源

随包内置的预置壁纸全部是本地副本，程序运行时不会从网络加载。

- `gothic-void.jpg`：`windows/presets/preset-gothic-void-crusade/background.jpg`
- `red-white.png`：`docs/images/hero-banner-red-white.png`
- `gallery-01.jpg` - `gallery-03.jpg`：`docs/images/gallery/skin-01.jpg` - `skin-03.jpg`

其中两张摄影类预置壁纸下载自 Unsplash，按 [Unsplash 许可协议](https://unsplash.com/license) 分发：

- `alpine-night.jpg`：[Unsplash 图片原始地址](https://images.unsplash.com/photo-1519608487953-e999c86e7455)
- `misty-peaks.jpg`：[Unsplash 图片原始地址](https://images.unsplash.com/photo-1464822759023-fed622ff2c3b)

这两张 Unsplash 摄影作品以本地文件形式随包提供，用于可选的壁纸功能。旧版的 `gallery-01.jpg` - `gallery-03.jpg` 为兼容历史安装仍保留在磁盘上，但它们属于宣传用界面素材，因此**有意不注册**为可选择的壁纸。

默认设置是不使用任何壁纸。你可以替换或往本目录里新增本地图片，然后在 `theme.js` 中注册它们。
