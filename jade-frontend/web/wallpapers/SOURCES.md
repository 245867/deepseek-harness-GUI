# Wallpaper sources

The bundled presets are local copies and are not loaded from the network at runtime.

- `gothic-void.jpg`: `windows/presets/preset-gothic-void-crusade/background.jpg`
- `red-white.png`: `docs/images/hero-banner-red-white.png`
- `gallery-01.jpg` - `gallery-03.jpg`: `docs/images/gallery/skin-01.jpg` - `skin-03.jpg`

The two photographic presets are downloaded from Unsplash and are distributed under the [Unsplash License](https://unsplash.com/license):

- `alpine-night.jpg`: [Unsplash image source](https://images.unsplash.com/photo-1519608487953-e999c86e7455)
- `misty-peaks.jpg`: [Unsplash image source](https://images.unsplash.com/photo-1464822759023-fed622ff2c3b)

The Unsplash photographs are bundled locally for the optional wallpaper feature. The old `gallery-01.jpg` - `gallery-03.jpg` files are retained on disk for compatibility with prior installations, but are intentionally not registered as selectable wallpapers because they are promotional UI imagery.

The default setting is no wallpaper. You can replace or add local images in this directory and register them in `theme.js`.
